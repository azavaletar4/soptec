1 Qué se construyó

Mismo patrón de seguridad que la Fase 4 (OLT): las credenciales del router nunca llegan al frontend, solo el backend (con service_role) las usa.

2 Decisión técnica: REST API, no la API binaria clásica

El material del curso tenía dos referencias distintas para MikroTik: la REST API moderna (RouterOS v7+, HTTPS, la que especifica el plan original de fases) y la API binaria clásica (puerto 8728, librería node-routeros, usada en otro documento del curso). Se eligió REST API por ser más simple (HTTP+JSON estándar, sin protocolo binario propio) y por ser la que pide explícitamente el plan de fases acordado.

Requisito en tu router: RouterOS v7 o superior, con el servicio www-ssl (o www sin TLS) habilitado y la REST API activa. Si tu router es v6 o más viejo, avísame para adaptar a la API clásica.
