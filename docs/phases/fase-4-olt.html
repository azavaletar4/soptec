2 Cómo se llegó ahí: diagnóstico paso a paso

Documentado para que quede el rastro de qué se descartó y por qué — útil si algo similar vuelve a pasar con otro equipo.

1. Primer intento por SSH → "502"Mensaje genérico, sin detalle. Bug encontrado: apiFetch solo leía el campo error de la respuesta, no message.
2. Corregido el mensaje → "ECONNRESET"Ya con el error real visible: la conexión SSH se cortaba sola.
3. Se descartó un problema de algoritmos criptográficosEl corte pasaba en 2-9ms, antes de cualquier intercambio de protocolo ("Connection lost before handshake") — demasiado rápido para ser negociación de cifrado.
4. Se probó conectividad de redping y Test-NetConnection (puertos 22 y 23) — ambos exitosos. El problema no era de red.
5. Se probó el cliente OpenSSH nativo de WindowsMismo resultado: Connection reset by 10.15.15.2 port 22. Esto descartó por completo la librería SSH de la app — el problema era del propio equipo.
6. El usuario compartió el panel de SmartOLTMostraba credenciales de Telnet (puerto 23), no de SSH, y "Reachable via VPN tunnel: Yes".
7. Prueba directa por Telnet → banner realWelcome to ZXAN product C300 of ZTE Corporation. Confirmado: esta OLT solo tiene Telnet habilitado.
8. Migración completa de SSH a TelnetNuevo cliente Telnet, mismos comandos de la CLI ZTE (el transporte cambia, la sintaxis de comandos no).
9. Validación de comandos contra el equipo realshow version resultó ambiguo (Error 20204); reemplazado por show gpon onu uncfg (funciona). El formato real de show gpon onu state no trae número de serie — parser corregido.

3 Qué está validado vs. qué falta

✅ Validado contra el equipo real

  • Conexión Telnet + login automático + modo enable
  • show gpon onu uncfg — ONUs sin configurar (con serial)
  • show gpon onu state gpon-olt_.../... — estado de ONUs configuradas (sin serial, corregido)
  • Test de conexión desde la app (/olt → "Probar conexión")

⚠ Sin validar — comandos de escritura

  • Registrar ONT nueva (onu ... type ... sn ... + tcont/gemport/service-port)
  • Activar / Desactivar (admin-state enable/disable)
  • Eliminar (no onu ...)
  • Señal óptica (show pon power attenuation)

No se ejecutaron sin tu confirmación explícita porque tocan servicio real de clientes. Antes de usarlas, probar con una ONU de repuesto o un puerto sin clientes activos.
