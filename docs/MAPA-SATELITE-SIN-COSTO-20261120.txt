DECISIÓN Y ALCANCE
Leaflet 1.9.4 + OpenStreetMap permanecen. Calles es el fondo inicial.
Satélite usa exclusivamente EOxCloudless 2016. Híbrido agrega el overlay
transparente de nombres y vías de EOX, construido con datos OSM/Natural Earth.
No hay cuenta, API key, tarjeta, suscripción ni facturación que activar.
No se añadieron dependencias ni infraestructura contratada.

comerciales y portales B2B. Exige atribución, uso razonable y no revender las
teselas originales como un conjunto GIS independiente. El servicio público no
tiene SLA ni cuota numérica garantizada: las ráfagas pueden limitarse o bloquearse.
Las capas 2018+ requieren licencia comercial pagada y quedan excluidas.
El servicio cartográfico permite incorporar sus overlays con créditos y enlace.
Se muestra la atribución a EOX/Copernicus 2016/CC BY 4.0; en Híbrido también
OSM y el renderizado EOX/MapServer. Deben conservarse los créditos en capturas.

  o desarrollo. No autoriza la operación comercial permanente de este panel.
  https://www.maptiler.com/cloud/pricing/
  https://www.maptiler.com/terms/cloud/
- Stadia Free: 200.000 créditos/mes; uso comercial no permitido. La prueba de

  https://stadiamaps.com/pricing/
  https://docs.stadiamaps.com/limits/
- Google Map Tiles: exige facturación activa, aun cuando exista un cupo gratuito.

  https://developers.google.com/maps/documentation/tile/usage-and-billing
- SentinelMap: anuncia 50.000 teselas/mes beta, CC BY-SA 4.0 y uso comercial,
  con registro GitHub y clave. Solo declara 4,13 millones de km² de cobertura;
  no se confirmó cobertura operativa en Perú ni se creó una cuenta. No integrado.
  https://www.sentinelmap.eu/
No se confirmó otra alternativa de alta resolución que satisfaga todas las
condiciones para este panel. No se promete equivalencia visual con Google.

IMPLEMENTACIÓN
- src/lib/zeroCostBasemaps.ts: lista cerrada de URLs HTTPS oficiales gratuitas.
  WMTS identifica s2cloudless_3857 como el mosaico 2016; overlay_bright_3857
  es la capa transparente. Orden WMTS: zoom/fila/columna, compatible con Leaflet.
- src/views/mapa/RedMapView.vue: selector de tres vistas, créditos y aviso de
  antigüedad/resolución. Solo reemplaza fondos; conserva capas de red, cámara,
  filtros, selección y borrador. No cambia el metraje registrado.
  Tras error EOX vuelve a OSM sin reintentos automáticos ni proveedor de pago.
  Un fallo OSM muestra aviso conservando infraestructura y edición.
  Carga tras finalizar desplazamientos, sin buffer fuera de vista ni precarga
  durante zoom. Se usa el caché HTTP normal del navegador, sin descarga masiva.
- deploy/map-route.env.example: explica que no se necesitan variables.
  Las antiguas variables Google/MapTiler se IGNORAN en el Mapa de Red. No pueden
  reactivar servicios por accidente. Adaptadores anteriores conservados en código
  e historial; ninguna importación activa de esos adaptadores en RedMapView.
- scripts/tests/zero-cost-basemap-browser.mjs: comprobación vigente de capas.
  El test anterior del editor solo actualiza expectativas del proveedor; sus
  escenarios de geometría no se repitieron. La prueba antigua de integración
  Google indica SKIP bajo la política S/0; no representa una validación Google.
